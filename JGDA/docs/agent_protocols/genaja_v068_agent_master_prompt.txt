SECTION 2 — PROBABILISTIC BRAIN MODEL

Mappings must be classified into states:

OBSERVED
INFERRED
SUGGESTED
CONFIRMED
REJECTED

Definitions:

OBSERVED
Column seen in dataset.

INFERRED
Possible mapping hypothesis.

SUGGESTED
High confidence candidate mapping.

CONFIRMED
Mapping successfully used in runtime execution.

REJECTED
Noise / placeholder / test artifact.

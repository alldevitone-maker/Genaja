# Genaja v0.6.4 - Release Notes

Genaja v0.6.4 introduces the **Evolution Memory Layer**, marking the first step towards local adaptive intelligence.

Genaja now learns from previous transformations and suggests mappings based on historical executions, significantly reducing manual effort in repetitive ETL tasks.

## Key Capabilities

*   **Persistent Learning Log**: Secure local storage of execution metadata.
*   **Context Signature Matching**: Intelligent recognition of column structures across different files.
*   **Usage-Based Prioritization**: Learns from user choices to suggest the most frequent mappings first.
*   **Secure Metadata-Only Storage**: Guarantees zero leakage of actual data cell content.

## Architecture Evolution

This release adds the `Learning Layer` to the core stack:
`User Input` → `File Intelligence` → `Validation / Lookup` → `Schema Mapping` → **`Evolution Memory`** → `Execution`

## Next Milestone

*   **Genaja Copilot**: Real-time AI assistance and active guidance (planned for v0.7.x).

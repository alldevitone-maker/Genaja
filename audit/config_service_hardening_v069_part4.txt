1. STATUS: ✅ CONCLUÍDO (HARDENED)
----------------------------------
O `ConfigService` foi blindado contra falhas comuns de IO e dados residuais, 
garantindo que o sistema nunca interrompa o runtime por problemas de configuração.

2. ARQUIVOS ALTERADOS
---------------------
- `src/core/services/config_service.py`

3. MUDANÇAS APLICADAS (DIVIDIDAS POR MECANISMO)
-----------------------------------------------
- **Baseline de Segurança**: `self.config` agora é inicializado com `DEFAULTS` 
  antes de qualquer tentativa de carregamento externo.
- **Deep Fallback**: Os métodos `get()` e `get_config()` verificam se a chave 
  existe no config carregado; caso contrário, recorrem automaticamente ao 
  esquema de defaults internos.
- **Carregamento Resiliente**:
  * Adicionado check de arquivo vazio (evita erro de `json.load`).
  * Adicionado check de tipo (`isinstance(dict)`) para o JSON lido.
  * Captura explícita de `json.JSONDecodeError` com fallback para `DEFAULTS`.
- **Fusão Inteligente**: Ao carregar, o sistema realiza uma fusão de campos 
  existentes, preservando os defaults para seções ou chaves ausentes no arquivo 
  físico.
